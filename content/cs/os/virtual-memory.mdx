# Virtual Memory

> This is a starter note. Its content will grow with the project.

## What is it?

Virtual memory gives a process its own address space. The operating system and hardware translate virtual addresses to physical memory.

## Why does it exist?

It isolates processes and lets programs use memory without managing physical locations directly.

## How does it work?

Page tables describe the mapping. A translation lookaside buffer caches recent translations.

## Trade-offs

Address translation and page tables cost time and memory. Page faults can be expensive.
