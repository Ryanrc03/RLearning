# LLM Engineering Overview

## 一句话

**这一章回答「不改模型怎么改答案」：先把输入拼好，再看输入之外还有什么进了窗口，最后看模型为什么会编、怎么少编。**

三页是一条问题链，每一页解决上一页留下的问题。每页都是五段：一句话、为什么需要它、怎么工作、代价与取舍、再往下看。

## 怎么读

按顺序读，每页 5 到 7 分钟，图里的开关和滑杆从头拨到尾再往下看。

第 1 页讲四种改输入的手段：角色、例子、先想再答、限制，拼出来就是一段 prompt。第 2 页把镜头拉远：那段 prompt 只占上下文窗口的一小段，记忆、检索、工具结果和状态都在抢同一根预算条。第 3 页回到生成那一步：下一个 token 是抽出来的，错的概率不为零，温度决定它多容易被抽到。

读完应该能用自己的话回答三个问题：few-shot 为什么比写规则管用；窗口溢出时先压哪一段；temperature 调低了为什么还会编。这一章之后接着去 Agent Harness，看这些东西怎么被放进一个带工具的循环里。
