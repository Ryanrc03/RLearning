# 相关性：Pearson r

## 一句话

**Pearson r 把两个变量的协方差除以各自的标准差，得到一个 −1 到 1 之间的数，量的是散点有多贴近一条直线。**

它是所有「x 和 y 有没有关系」的第一个数字，也是最容易被读过头的一个。

## 为什么需要它

气温和奶茶销量放在一张散点图上，看得出「一起动」，但一起动得多紧、是正是负，眼睛说不准，换个坐标轴刻度看起来又不一样。协方差 cov(x, y) 能量方向，可它带着单位：气温用 °C 还是 °F、销量用杯还是打，数值差好几倍。把 cov 除以 s_x · s_y，单位就消掉了，剩下的 r 只和点的形状有关。r 回答的是「知道 x 以后，猜 y 能好多少」这一类问题；它不回答「是不是 x 让 y 变的」，这一章后面的页都在处理这个差别。

## 怎么工作

<CorrelationFigure />

$$
r = \frac{\sum_i (x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum_i (x_i-\bar x)^2}\,\sqrt{\sum_i (y_i-\bar y)^2}} = \frac{\mathrm{cov}(x, y)}{s_x\, s_y}
$$

分子里每一项是一个点相对中心 (x̄, ȳ) 的「同向程度」：x 和 y 同时偏高或同时偏低，这一项是正的；一高一低是负的。全是正项加起来，r 接近 1，点贴着一条上升的直线；正负各半，抵消成 0，云团是圆的；全是负项，r 接近 −1。分母把 x 和 y 各自的尺度除掉，所以 °C 换成 °F，r 一点不变。

线性情景里拖 r，同一批点绕着中心转：r = 0.7 时云团是斜的椭圆，r 到 0.95 以上几乎成一条线。右边的 r² 是「一条直线能解释 y 方差的比例」，r = 0.7 也只解释了一半。

另外两个情景是 r 看不见的东西。U 形里 y 完全由 x 决定，r 却几乎是 0，因为左半边负项和右半边正项抵消了。「冰淇淋与溺水」里 r 有 0.6，但点的颜色暴露了第三个变量：热天冰淇淋卖得多，热天下水的人也多。把气温固定住再算，偏相关 r(x, y | z) 掉到 0 附近。一个相关可以来自 x → y、y → x、z 同时推着两边，或者样本小碰巧撞上；r 本身分不出这四种。

## 代价与取舍

- **只量直线**：r ≈ 0 只说明没有线性关系，U 形、周期、分段都量不出来。先画图，再看数字。
- **说不出斜率**：r = 0.9 可以是每度多卖 1 杯，也可以是每度多卖 100 杯。r 说的是「贴得多紧」，斜率要看下一页的回归。
- **怕离群点**：一个离中心很远的点在分子里贡献巨大，几十个点的样本里，一个异常日就能把 r 从 0.2 拉到 0.6。
- **聚合会骗人**：按城市平均再算相关，和按用户算相关，方向都可能相反（Simpson 悖论）。看清 r 是在什么单位上算的。
- **r² 是解释方差的比例**，不是「预测准不准」；方差本来就小的 y，r² 很高也没多少实际意义。
