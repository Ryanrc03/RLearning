# A/B Testing Overview

## 一句话

**这一章回答「差异是真的还是运气」：先弄清为什么平均值总是正态的，再用这个事实做假设检验，然后解释为什么要在看数据之前先画好一条拒绝线，最后用一个抽卡的例子把三件事串起来。**

## 怎么读

按顺序读，每页 5 到 7 分钟，图里的控件从头拖到尾再往下看。

第 1 页是地基：中心极限定理说，不管单个数长什么样，n 个数的平均值都近似正态，宽度是 σ/√n。后面所有的 z、p-value、临界值都建立在这句话上。第 2 页用一碗饭讲假设检验的逻辑：先假设没区别，再问看到的数据有多不寻常，p-value 就是这个「不寻常」的度量。第 3 页解释为什么不能看完数据再决定：α 是你愿意承担的冤枉率，拒绝域是 H0 下面积恰好等于 α 的那一截尾巴，α 和 β 此消彼长，只有加大样本才能两头都好。第 4 页是例子：一个游戏公示 SSR 概率 1%，一个人抽 500 次能不能说它暗改了，全服玩家一起记录又能不能。

Evaluation 那一章的 [A/B Test 与 p-value](/notes/ml/evaluation/ab-test-p-value/) 和 [t 检验](/notes/ml/evaluation/t-test/) 用的就是这里推出来的东西：前者把同一套检验用在两组转化率上，后者在 σ 未知、样本又少的时候把正态换成 t 分布。先读这一章，再回头看那两页，公式里每一项为什么长那样就都有了来历。

读完应该能用自己的话回答四个问题：为什么样本平均值是正态的而单个样本不是；p = 0.03 是「H0 成立时看到这么极端数据的概率」而不是「H0 成立的概率」；为什么 α 要在看数据之前定；样本量和 power 是什么关系。
