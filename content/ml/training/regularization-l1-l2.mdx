# Regularization：L1 与 L2

## 一句话

**在 loss 后面加一项对权重大小的惩罚：L2 把所有权重整体压小，L1 把不重要的权重直接推到 0。**

几乎所有模型都带一个这样的 λ，从线性回归的 ridge 到 LLM 训练里的 weight decay。

## 为什么需要它

上一页过拟合的曲线有一个共同特征：为了穿过每一个噪声点，多项式的系数变得很大、正负交替。只看训练误差，模型没有理由不这么做。正则化的办法是改目标：数据 loss 之外，再为「权重有多大」付一笔钱，让模型在拟合和简单之间自己权衡，λ 就是这笔钱的价格。

## 怎么工作

<RegularizationFigure />

$$
L(\theta) = L_{\text{data}}(\theta) + \lambda\, \Omega(\theta)
$$

$$
\text{L2 (Ridge)}:\ \Omega = \tfrac{1}{2}\lVert\theta\rVert_2^2 = \tfrac{1}{2}\sum_i \theta_i^2,\qquad \text{L1 (Lasso)}:\ \Omega = \lVert\theta\rVert_1 = \sum_i \lvert\theta_i\rvert
$$

图里的数据 loss 是一个二维的二次碗，等高线是椭圆，中心 w* 是不加惩罚的最优解。加了惩罚之后，解不再是椭圆中心，而是椭圆和一条惩罚等值线相切的地方：L2 的等值线是圆，L1 的是菱形。λ 越大，解被拉得离原点越近。

两边的差别全在形状上。圆是光滑的，椭圆碰到它的切点可以在任何角度，几乎不会正好落在坐标轴上，所以 L2 的两个权重都变小，但都不是 0。菱形有四个角，角正好在坐标轴上；椭圆从外面逼近时最先碰到的往往是角，切点一落在角上，那个坐标就是精确的 0。拖 λ 过 1.1，L1 的 w₂ 就归零了，L2 的 w₂ 还有 0.57。

从梯度看是同一件事：L2 的梯度是 λθ（这也是 Ω 里那个 ½ 的用处），权重越小推力越小，永远推不到 0；L1 的梯度是 λ·sign(θ)，权重再小推力也一样大，能把它推过 0 并钉在那里。线性模型下 L2 有闭式解 (H + λI)⁻¹ H w*，L1 没有，图里用的是坐标下降加 soft-thresholding。

## 代价与取舍

- L2 稳定、处处可导、有闭式解，是默认选择；深度学习里的 weight decay 就是它。它不做特征选择，所有权重都留着。
- L1 给出稀疏解，可以当特征选择用，模型也更好解释；代价是 0 处不可导、优化慢，特征强相关时它会随便挑一个留下。
- λ 要用 dev 集调：太小没用，太大就欠拟合，上一页的 bias 又回来了。
- 惩罚项对权重的尺度敏感，特征要先标准化；偏置项 b 通常不惩罚。
- 正则化不只这两种：dropout、early stopping、数据增强都在做同一件事，限制模型记噪声的能力。
