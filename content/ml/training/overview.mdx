# Training Overview

## 一句话

**这一章回答「loss 怎么降下去」：先沿负梯度一步步走，再看训练 loss 降了测试为什么没降，最后在 loss 后面加惩罚项治过拟合。**

三页是一条问题链，每一页解决上一页留下的问题。每页都是五段：一句话、为什么需要它、怎么工作、代价与取舍、再往下看。

## 怎么读

按顺序读，每页 5 到 7 分钟，图里的控件从头拖到尾再往下看。

第 1 页是所有训练的底层动作：梯度指向哪里，为什么一个学习率伺候不了所有方向，Momentum、RMSProp、Adam 各自补了什么。第 2 页从「loss 降了」转到「模型好不好」：把误差拆成 bias 和 variance，用训练误差和测试误差的差距做诊断。第 3 页给出最直接的药：L2 把权重压小，L1 把权重推到 0，两者的差别只在惩罚项的形状。

读完应该能用自己的话回答四个问题：SGD 的噪声从哪来、为什么不全是坏事；Adam 和 RMSProp 差在哪一步；训练误差高和训练 / 测试差距大分别该怎么治；为什么 L1 会把权重精确地推到 0 而 L2 不会。
