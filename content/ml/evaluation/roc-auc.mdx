# ROC 与 AUC

ROC 曲线记录分类阈值从高到低时，模型找出多少正例、误报多少负例。AUC 是曲线下面积，用来比较模型的排序能力。实际做预测时，仍要根据误报和漏报的成本选一个阈值。

## 阈值怎么画成一条曲线

将分数大于等于阈值的样本判为正例。ROC 的横轴 FPR 是被误报的负例占全部负例的比例，纵轴 TPR 是被找出的正例占全部正例的比例，也就是 recall。

$$
FPR = \frac{FP}{FP + TN},\qquad TPR = \frac{TP}{TP + FN}
$$

阈值高于所有分数时，曲线从 (0, 0) 出发。每次把阈值降到下一个分数，纳入这一整组样本，记下新的 (FPR, TPR)。当所有样本都被判为正例时，曲线到达 (1, 1)。曲线越贴左上角，模型就越能在同样的误报率下找出更多正例。

## 用 NumPy 算一遍

下面有两个正例和两个负例。拖动滑杆到 0.8，观察两个同分样本怎样一起进入 ROC 曲线。

<RocAucSweepFigure />

先数出正负例各两个。用 `np.argsort` 拿到分数降序的索引，再用同一个索引重排标签，保证每个标签还跟着原来的分数。对正例和负例的指示数组分别做 `np.cumsum`，得到扫描到每一行时的 TP 和 FP。

比较相邻分数，用布尔掩码只保留每组的最后一行。阈值降到 0.8 时，两个同分样本一起进入，累计 TP 为 2，FP 为 1，ROC 点从 (0, 0.5) 走到 (0.5, 1)。阈值高于最大分数时谁都没进来，所以还要在最前面补上 (0, 0)。

每段面积等于横向宽度乘两端的平均高度。`np.diff(fpr)` 算宽度，相邻两个 TPR 的均值算高度。第一段竖直，面积为 0；后两段面积是 0.375 和 0.5，加起来是 0.875。用正负配对也能核对：四对里赢三对、平一对，平局算半对，得到 (3 + 0.5) / 4 = 0.875。

<a href="/labs/evaluation/roc_auc.py" download="roc_auc.py">下载 NumPy 实现</a>。运行 `python roc_auc.py` 会打印这个例子的结果。

```python
import numpy as np

def calculate_auc(y_true, y_scores):
    y_true = np.array(y_true)
    y_scores = np.array(y_scores)

    # Count positive and negative samples
    n_pos = np.sum(y_true == 1)
    n_neg = np.sum(y_true == 0)

    if n_pos == 0 or n_neg == 0:
        return 0.0

    # Sort by prediction scores
    sorted_indices = np.argsort(y_scores, kind="mergesort")[::-1]
    y_true_sorted = y_true[sorted_indices]
    y_scores_sorted = y_scores[sorted_indices]

    # Cumulative TP and FP
    tps = np.cumsum(y_true_sorted == 1)
    fps = np.cumsum(y_true_sorted == 0)

    # Handle tied scores
    last_of_group = np.append(
        y_scores_sorted[1:] != y_scores_sorted[:-1],
        True
    )

    tps = tps[last_of_group]
    fps = fps[last_of_group]

    # Compute ROC coordinates
    tpr = tps / n_pos
    fpr = fps / n_neg

    # Add origin (0, 0)
    tpr = np.concatenate([[0], tpr])
    fpr = np.concatenate([[0], fpr])

    # Trapezoidal integration
    auc = np.sum(
        np.diff(fpr) *
        (tpr[1:] + tpr[:-1]) / 2
    )

    return float(auc)


if __name__ == "__main__":
    y_true = [0, 1, 0, 1]
    y_scores = [0.2, 0.9, 0.8, 0.8]
    print(calculate_auc(y_true, y_scores))  # 0.875
```

排序耗时 $O(n \log n)$，索引和中间数组占用 $O(n)$ 空间。输入应是等长的一维数组，标签取 0 或 1，分数为有限数值。只有一类时 AUC 未定义，示例代码约定返回 0.0。正负例都存在时，全部同分得到 0.5，完美排序得到 1，完全反向排序得到 0。

AUC 衡量排序，分数整体偏高或偏低仍可能得到相同的 AUC。若业务只关心低误报区间，可以直接比较那一段 ROC。正例很少时，可以看 [PR 曲线与 Precision@k](/notes/ml/evaluation/pr-curve-precision-at-k/)。推荐系统要比较每位用户的排序效果时，可以看 [GAUC 与配对用户 bootstrap](/notes/ml/recsys/gauc-paired-bootstrap/)。
