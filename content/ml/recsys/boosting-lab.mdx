# 提升树训练实验台

神经网络的参数是一组固定数量的权重，训练改的是这些数值。提升树不同：它的"参数"就是树本身，每轮训练**新增一棵树**，已有的树不再改动。这件事光看公式不容易有体感，所以这篇笔记的主体是一个实验台：16 个点、1 个特征，按一轮长一棵树，看残差怎样被压小、LogLoss 怎样一点点下降、模型里到底存了什么。

## What is being trained?

两种模型的"训练"放在一起看，差别一眼就能看出来：

```text
神经网络    在参数空间做梯度下降：θ ← θ − η ∇L(θ)
提升树      在函数空间做梯度下降：
            每轮先算损失对每条样本分数的梯度 g = p − y，
            用一棵树去近似 −g，把这棵树整体当作一步加进去
```

所谓梯度下降发生在"每条样本的分数 `F(x_i)`"上：新树去拟合负梯度 `y − p`，乘一个小的学习率加到分数里，LogLoss 就下降一点。决定树的数量的是早停，所以参数总量在训练结束才知道。

GBDT、XGBoost、LightGBM 是同一个框架的三种实现，差在三处：怎样给叶子赋值（一阶残差均值还是二阶 `−G/(H+λ)`）、在哪些候选点上找切分（所有取值还是直方图桶边）、按什么顺序长树（按层还是按叶子）。实验台把这三组差别做成了开关。

## How to use the lab

数据是 16 条曝光，只有一个特征 `x ∈ [0, 1]`，标签 `y` 在 `x` 落在 0.34 到 0.70 之间时多为 1，另有两个"噪声点"（`x = 0.52` 没点，`x = 0.90` 点了）。初始模型是常数 `F_0 = ln(7/9) = −0.251`，所有点 `p = 0.4375`。

- **走一轮**：按当前方法长一棵树并加进模型；**播放**自动走到 30 轮；切换方法会重置。
- 上图蓝线是当前模型的 `p(x)`，竖线是每个点的残差 `p − y`，越短越好；中图是本轮新树在 `x` 轴上的样子，蓝柱把分推高、红柱拉低，虚线是切分位置；右上角是 LogLoss 曲线。
- **森林**把每棵树按真正的树形画出来，新树从右边长出。点击任意样本点，蓝色路径是它在每棵树里走的路，最下面的曲线是它的分数一棵一棵累加的过程。
- **固定当前曲线做对比**可以叠加最多 3 条 LogLoss 曲线。

值得试的几件事：把学习率调到 1.0 看曲线怎样变得毛躁；把 `λ` 从 1 调到 3 看叶子值怎样缩水；LightGBM 下把 `max_bin` 从 8 改成精确，看切分从 0.375 跳到 0.315。

## What happens in one round?

记第 `m` 轮开始时每条样本的分数为 `F_i`，概率 `p_i = σ(F_i)`。LogLoss 对 `F_i` 的一阶导和二阶导分别是：

```text
g_i = p_i − y_i        h_i = p_i (1 − p_i)
```

新树把样本切成若干叶子，每个叶子给一个常数 `w`。三种实现在这一步分叉：

```text
GBDT（一阶）              w_j = mean(−g_i) = Σ(y_i − p_i) / n_j
                          切分看残差的平方误差下降

XGBoost / LightGBM（二阶）
                          w_j  = −G_j / (H_j + λ)
                          gain = G_L²/(H_L+λ) + G_R²/(H_R+λ) − G²/(H+λ)
```

二阶版本是**牛顿法**：用曲率 `h` 给残差做归一化。`h = p(1−p)` 在 `p` 接近 0.5 时最大、接近 0 或 1 时最小，所以同样的残差，在模型还不确定的地方步子小，在模型已经很确定的地方步子大。实验台里能直接看到：XGBoost 第一棵树的叶子值约 ±1.0，而一阶的 GBDT 只有 ±0.44，所以 XGBoost 的 LogLoss 降得最快。`λ` 加在分母上，是给这个放大器装的闸：`H` 很小的叶子步子被压住，样本少的叶子缩向 0。

然后所有实现都做同一件事：

```text
F_i ← F_i + ν · w_leaf(i)
```

学习率 `ν` 就是让曲线平滑或毛躁的那个旋钮。它小，每棵树只走一小步，需要更多树，但更稳；真实模型用 0.05，走了 407 步。

## GBDT vs XGBoost vs LightGBM

三者共用同一个框架，差别全在"怎样长一棵树"和"怎样算得快"。实验台里能看到的只有前三行，后面几行是大数据上才显现的工程取舍。

| | GBDT（Friedman 2001） | XGBoost（Chen & Guestrin 2016） | LightGBM（Ke et al. 2017） |
| --- | --- | --- | --- |
| 叶子值 | 按平方误差拟合残差，叶子取残差均值 | 二阶：−G/(H+λ) | 二阶，同 XGBoost |
| 切分候选 | 特征的所有取值（精确） | 精确，或加权分位数草图近似 | 直方图：先分成 ≤255 个桶，只在桶边上找 |
| 生长顺序 | 按层，到 max_depth | 按层，到 max_depth；γ 做剪枝 | 按叶子：每次只分裂增益最大的叶子，到 num_leaves |
| 正则 | 学习率、子采样 | λ、α、γ、min_child_weight、列采样 | λ、min_data_in_leaf、feature_fraction、bagging |
| 缺失值 | 需先填补 | 每个节点学一个默认方向 | 同 XGBoost |
| 类别特征 | 需先编码 | 需编码（新版支持原生） | 原生：按 G/H 排序后找最优子集 |
| 加速 | 无 | 并行、缓存感知、核外计算 | 直方图相减、GOSS、EFB |

在实验台的 16 个点上，三条曲线的差别来自两处：XGBoost 和 LightGBM 的牛顿步比 GBDT 的残差均值大，所以前两者降得快；LightGBM 默认 8 个桶，第一刀只能落在 0.25 和 0.75（精确切分是 0.315 和 0.735），所以它在这个小数据上反而最慢，把 `max_bin` 改成精确后曲线几乎和 XGBoost 重合。**三者是同一种算法，差别在近似。** 真正拉开差距的是 502 万行 × 84 列这种规模：直方图让每轮找切分的代价从"行数"降到"桶数"，按叶子生长让同样的叶子数换来更低的损失，原生类别特征省掉了 26 列的编码。

## From 16 points to 5 million rows

| | 实验台 | KuaiRand click 模型 |
| --- | --- | --- |
| 数据 | 16 个点，1 个特征 | 5,021,422 行，84 个特征 |
| 树的容量 | num_leaves 3，max_bin 8 | num_leaves 127，max_bin 255，min_data_in_leaf 200 |
| 步长与轮数 | ν = 0.3，最多 30 轮 | ν = 0.05，验证集 AUC 50 轮不涨就停，实际 407 轮 |
| 初始分 | F₀ = ln(7/9) = −0.251 | F₀ = ln(0.3806/0.6194) = −0.487 |
| 参数 | 每棵树 2 个阈值 + 3 个叶子值 | 每棵树 126 个切分 + 127 个叶子值，407 棵约 10 万个数 |
| LogLoss | 从 0.685 往下 | train 从 0.662 往下，test 0.517 |

真实模型 159 秒训完 407 棵 127 叶子的树；用 Friedman 原版实现大约要慢一到两个数量级。

## Three common misconceptions

- **"训练在调树的权重。"** 不是。每棵树乘的都是同一个固定的 `ν`，没有被学习的"树权重"；被学的是树的结构和叶子值，而且只在它被创建的那一轮学一次。
- **"学习率越小越好。"** 它只换来更多的树。`ν = 0.05` 配 407 轮和 `ν = 0.1` 配约 200 轮效果接近，前者略稳，训练时间翻倍。
- **"loss 一直在下降说明还该继续训。"** 训练集的 LogLoss 几乎单调下降，但验证集的 AUC 会先升后平再降，早停看的是后者。决定树数量的从来不是训练损失。

## Key ideas to remember

1. 提升树在**函数空间**做梯度下降，每轮加一棵树，旧树不动。
2. 树拟合的目标是梯度 `p − y`，不是标签。
3. 一阶（残差均值）和二阶（`−G/(H+λ)`）的差别就是有没有用曲率 `h` 做归一化；`λ` 是刹车。
4. 直方图、leaf-wise、原生类别特征都是近似和工程取舍，在小数据上看不出好处，在百万行上才是决定性的。
5. 树的数量由验证集早停决定，不由训练损失决定。
